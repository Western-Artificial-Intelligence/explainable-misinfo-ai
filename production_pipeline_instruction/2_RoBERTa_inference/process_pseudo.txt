# 2_RoBERTa_inference/process_pseudo.txt
# Assumption: roberta_infer(text) exists and returns:
#   h (CLS embedding), label_logits[3], label_probs[3]
# NOTE: This production pipeline uses ONLY the 3-way label head {false,mixed,true}.
#       A 4-way label space (e.g., including NEI) is NOT produced here.

INPUT:
  {
    request_id,
    claim_id,
    user_claim,
    normalized_claim,
    meta: { received_at, version, warnings? }
  }

CONSTANTS:
  LABELS_3WAY = ["false", "mixed", "true"]
  CTX_TOKENS_MAX = 512                 # RoBERTa architectural max
  T_DEFAULT = 256                      # paper default; can be configured to 512 :contentReference[oaicite:1]{index=1}

PROCESS:
1) Build model input text x
   - For claim-only inference in prod:
       x = "<CLAIM> " + normalized_claim + " </CLAIM>"
     (Sentinel tokens are part of the tokenizer vocab extension in the paper.) :contentReference[oaicite:2]{index=2}

2) Tokenize
   - tokens = tokenizer(x, max_length = T_CONFIG, truncation = true, padding = "max_length")
   - input_tokens = count_nonpad(tokens.attention_mask)
   - truncated = (original_token_count(x) > T_CONFIG)

3) Run model
   - start_timer()
   - pred = roberta_infer(tokens.input_ids, tokens.attention_mask)
       where:
         pred.h              = pooled CLS embedding h = last_hidden_state[:,0,:] :contentReference[oaicite:3]{index=3}
         pred.label_logits   = logits over {false,mixed,true} :contentReference[oaicite:4]{index=4}
         pred.label_probs    = softmax(pred.label_logits) :contentReference[oaicite:5]{index=5}- latency_ms = stop_timer_ms()

4) Postprocess label prediction
   - probs3 = pred.label_probs
   - class_id = argmax(probs3)
   - class_name = LABELS_3WAY[class_id]
   - confidence = probs3[class_id]

5) Compose output
   OUTPUT = {
     request_id,
     claim_id,
     user_claim,
     normalized_claim,

     roberta: {
       label: {
         logits: pred.label_logits,
         probs: probs3,
         class_id: class_id,
         class_name: class_name
       },
       confidence: confidence,

       # optional, if you want downstream MMR/semantic routing
       embedding: pred.h,

       # optional, if you want to log it (not used for decision)
       domain: {
         logits:         probs:         source_id_hat: argmax(       },

       model: {
         name: "roberta-base(+lora)",
         revision: MODEL_REVISION,
         ctx_tokens: CTX_TOKENS_MAX,
         T_used: T_CONFIG
       },

       tokenization: {
         truncated: truncated,
         input_tokens: input_tokens
       }
     },

     meta: {
       received_at: meta.received_at,
       version: meta.version,
       warnings: meta.warnings?,
       latency_ms: latency_ms
     }
   }

RETURN OUTPUT

----------------------------------------
DETERMINISM / TIE-BREAKING (PROD)
----------------------------------------
Goal: avoid flaky outputs when sorting or taking argmax over floats.

Definitions:
  EPS = 1e-9  (treat |a-b| <= EPS as a tie)

Rules:
  1) Never rely on dict/map iteration order for ranking.
  2) Any argmax must define a deterministic tie-break order.
  3) Any sort must define secondary/tertiary keys (stable IDs).

Stage 2 (RoBERTa inference):
  - label_class = argmax(label_probs)
      tie-break: if multiple classes tie within EPS, choose the earliest class in LABELS_3WAY order.
  - domain_class = argmax(domain_probs)
      tie-break: if multiple classes tie within EPS, choose the earliest class in DOMAINS_5WAY order.
